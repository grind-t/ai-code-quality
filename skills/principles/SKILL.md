# Code quality principles

## Design

DESIGN-001: Generalize hidden duplication

DESIGN-002: Make illegal states unrepresentable

DESIGN-003: Prefer composition over parameterization

DESIGN-004: Prefer well-maintained library over custom code

## Naming

NAMING-001: Name says exactly what the code does

NAMING-002: One word per concept

NAMING-003: Readable at the call site

NAMING-004: Don't add gratuitous context
